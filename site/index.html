桌面该有的样子

不是又一个文件管理器，而是让你的桌面自己收拾干净。

🗂️

智能分组

按文件类型（图片 / 视频 / 文档 / 代码…）或日期（今天 / 本周 / 本月…）自动归类，130+ 扩展名覆盖。

👆

单击选中 · 双击打开

和 macOS 一致的交互手感。点一下高亮选中，再点一下直接打开，原生桌面图标照常可点。

🖱️

拖拽排列

叠放堆可自由拖动，松手自动吸附到网格，像摆弄真实桌面图标一样顺手。

🎴

网格 / 扇形布局

展开方式随你切，网格整齐、扇形灵动，总有一款顺眼。

⚡

秒开不卡顿

图标异步加载，启动瞬间完成，再也不会有「点了没反应」的死等。

🚀

开机自启

注册表一键启用，登录后桌面自动归位，开机即清爽。

📂

多源分类

桌面 + 任意文件夹混合分类，每个源独立扫描、按名去重，文件仍留在原处不挪窝。

📝

自定义分类规则 v1.0.3

不满足于内置分组？在「按自定义规则」里把任意扩展名归到专属叠放栏——比如「工作资料」=\.pdf,.docx,.xlsx，未匹配自动归入「其他」。

🏷️

自定义叠放栏名称 v1.0.3

不喜欢内置的「图像 / 文稿 / 演示文稿」？在设置里给任意叠放栏起自定义名，留空即可恢复默认。

怎么做到的

一层透明叠放层，叠在你的原生桌面之上。

  1. 1

    全屏透明叠加

    应用开一个全屏透明窗口自绘叠放堆，原生图标层保持共存、照常可点。

  2. 2

    Win32 点击穿透

    用 WM_NCHITTEST 消息精确判断：点在堆上就拦截，点在空白就穿透到桌面。

  3. 3

    虚拟分组，零改动

    分组只是「视图」，文件原封不动待在原处——误删？不存在的。
